# Medicine Refrigerator Monitoring System

## Introduction

The Medicine Refrigerator Monitoring System is an IoT-based project for monitoring the environmental conditions and operational status of refrigerators used to store medicines. Its purpose is to help users see important refrigerator conditions and receive alerts when attention may be needed.

## Planned Features

- Temperature and humidity monitoring
- Refrigerator door activity detection
- Power monitoring
- Remote monitoring and alerts

## Proposed Hardware

The project is evaluating an nRF52832 sensor node, an SHT31 temperature and humidity sensor, and an ESP32-C3 SuperMini gateway.

## Software Technologies

Planned technologies include Firebase, HTML, CSS, and JavaScript.

##Status

The project is in the planning and hardware evaluation stage. Hardware choices, architecture, and implementation details are still being explored.
